# 34. The Great Tao Flows Everywhere

*Part I: The Way · 《大道泛兮》*

## The Verse

大道泛兮，其可左右。

万物恃之而生而不辞，功成不名有。衣养万物而不为主，常无欲，可名于小；万物归焉而不为主，可名为大。

以其终不自为大，故能成其大。

The great way flows everywhere. It can go to the left or to the right.

The ten thousand things rely on it for life, and it does not turn them away. When the work is done, it does not claim it. It clothes and feeds the ten thousand things and does not act as their master. Always without desire, it can be called small. The ten thousand things return to it and it does not act as their master, so it can be called great.

Because it never makes itself great, it can become great.

*The Chinese is the received Wang Bi text. The translation is the author's own.*

## The Trader

1. A system that works flows everywhere and does not need watching. If it needs you every hour, it is not yet a system.

2. It can go left or right: long, short or flat, as the rule finds. It does not need you to have a side.

3. The things rely on it and it does not turn them away. Every candidate gets the same checks, the dull ones and the exciting ones alike.

4. When the work is done, it does not claim it. Do not take credit for the rule's good weeks. You did not make them. You only did not get in the way.

5. Do not take the blame for its bad weeks either, unless you touched it. If you touched it, the week is yours.

6. It does not act as master. The scheduled run runs. Read the log afterwards, not the screen during.

7. Always without desire, it can be called small. A good system has no wish to trade. It trades when the rule says so, and otherwise it waits.

8. The first week you let it run without checking every hour is the week you learn whether you built a system or a habit of watching.

9. Because it never makes itself great, it becomes great: small rules, run every day, without your name on them.
